# TG Post Scheduler

Бот-планировщик постов для Telegram-каналов: загрузил контент → выбрал каналы →
назначил время публикации и автоудаления → бот сам всё сделал.

## Возможности

- Публикация текста / фото / видео / **альбомов** (несколько фото и видео в одном посте) по расписанию (или сразу)
- Форматирование текста (жирный, курсив, ссылки) и **premium-эмодзи** сохраняются как есть
- Один и тот же пост можно разослать сразу в несколько каналов одной кнопкой
- Автоудаление поста через 24 / 48 / 72 часа (или без удаления) — индивидуально для каждого канала
- **Редактирование текста** уже созданного поста через /myposts — включая посты, которые
  уже опубликованы (текст/подпись обновится "вживую" во всех каналах), медиа при этом не трогается
- Медиафайлы не скачиваются и не проходят через сервер бота — используется Telegram `file_id`,
  поэтому нагрузка на сервер минимальна

## Как это устроено

- `bot/main.py` — точка входа, поднимает бота и два фоновых воркера
- `bot/scheduler.py` — воркер публикации (раз в N секунд проверяет БД на "пора постить")
  и воркер автоудаления (проверяет "пора удалить")
- `bot/handlers/` — команды и диалоги (aiogram FSM)
- `schema.sql` — схема Postgres, накатывается автоматически при старте

## Локальный запуск

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# впиши в .env свой BOT_TOKEN и DATABASE_URL (нужен запущенный Postgres)

python -m bot.main
```

## Деплой на Railway

1. Создай новый проект на Railway, подключи этот репозиторий (GitHub) или
   загрузи код через Railway CLI.
2. Добавь в проект плагин **Postgres** — Railway сам создаст переменную
   `DATABASE_URL` и подставит её в сервис бота (Variable Reference).
3. В переменных сервиса бота добавь:
   - `BOT_TOKEN` — токен из @BotFather
   - `TIMEZONE` (опционально, по умолчанию `Europe/Moscow`)
4. Railway автоматически определит `Procfile` и запустит `worker: python -m bot.main`.
   Отдельный веб-порт не нужен — это фоновый процесс с long polling, не веб-сервис.
5. При первом старте бот сам создаст таблицы в БД (`schema.sql` применяется автоматически).

Тарифа Hobby ($5/мес) с большим запасом хватает: бот не скачивает медиафайлы,
основная нагрузка — лёгкие вызовы Telegram Bot API и пара запросов к Postgres
раз в 20 секунд.

## Как пользоваться ботом

1. Добавь бота администратором в канал с правами **"Публикация сообщений"**
   и **"Удаление сообщений"**.
2. В личке боту: `/addchannel`, затем перешли любое сообщение из канала —
   бот проверит права и подключит канал.
3. Пришли боту текст, фото или видео (с подписью, если нужно) — это станет постом.
4. Отметь галочками, в какие каналы постить (можно сразу несколько).
5. Выбери, когда удалить пост: через 24 / 48 / 72 часа или никогда.
6. Выбери, когда опубликовать: сейчас, через 1/3 часа, либо укажи точную дату и время
   вручную (`31.12.2026 15:30`).
7. Готово — бот опубликует и (если назначено) удалит пост автоматически, без твоего участия.

Полезные команды:
- `/channels` — список подключённых каналов
- `/removechannel` — отключить канал
- `/myposts` — список последних постов; выбери пост → «✏️ Изменить текст» — можно
  поменять текст/подпись даже у уже опубликованного поста (медиа не меняется, только текст)
- `/cancel` — отменить текущий сценарий создания поста

### Альбомы

Просто пришли боту несколько фото/видео одним сообщением (как обычно в Telegram —
выделяешь несколько файлов и отправляешь разом). Бот подождёт секунду-две, соберёт
все части в один альбом и дальше поведёт себя как с обычным постом: выбор каналов,
времени, автоудаления. Подписью станет текст, добавленный к любому из файлов альбома.

## Важно про удаление сообщений

Если бот — администратор канала с правом "Удаление сообщений", он может удалить
собственный пост в любой момент, без стандартного 48-часового ограничения Telegram
(это ограничение действует только для обычных участников без прав администратора).

## Возможные доработки

- Поддержка альбомов (несколько фото/видео в одном посте, media group)
- Редактирование уже запланированного, но ещё не опубликованного поста
- Просмотр списка всех запланированных постов с кнопкой отмены
- Часовой пояс на пользователя, а не глобальный
